What changes at the API boundary?

Existing API · main / review family

The typed decoder has an input lifetime. Erased jobs and decoders introduce boxes; typed callers can avoid those erasure boxes. Source contract

Reimagined · captured protocol

One object-safe step loop

codec.decoder(&spec)
  -> Box<dyn Decoder>

decoder.requested()
decoder.step(
  Input<'_>, sink
)

Each step borrows its input. The decoder itself is Send + 'static; it cannot retain a parser borrowing the caller’s file between steps. The current spec stores SharedPulse.

Measured cost control · experimental

Borrow through the operation

  &self,
  bytes: &[u8],
  pulse: &dyn Pulse,

Typed and erased calls borrow both arguments. They need no per-call codec box or Pulse sharing. This control does not provide the complete policy/admission or collection surface.

What the resident repair actually removed

Before the repair, the synthetic positioned path added 4,000 calls per 1,000 decodes and inline Tokio added 5,000. After repair: 2,000 and 3,000. Original-allocation pointer controls cover whole input, ranges and async yields. The older typed synthetic path remains at 1,000 calls, so the box has not disappeared.

Native qualification and limits

All eight routes match exact dimensions, descriptors and samples for 8, 63 and 256 square witnesses. Native output pointers survive extraction and PixelBuffer adoption. QOI/BMP use a frozen zenbitmaps export with two probe/ownership accessors; JPEG uses the retained PR260 dependency cohort. The bitmap source verifier proves those accessors are the only changes. This is RGB8 success-path evidence, not full codec conformance, arbitrary metadata/color/orientation coverage or a native workspace bound.

&dyn Pulse belongs on the local path

Caller’s slice + borrowed Pulse→Native decode→Move owned pixels

The control Pulse borrows stack counters and refuses share(). Native cancellation still reports the original timeout cause. JPEG sends progress through that borrowed Pulse; the bitmap raw APIs qualify cancellation only because they currently accept Stop.

The current WholeImageDecode::decode hook receives no Pulse. Its outer checks cannot provide native in-flight progress or cancellation on their own. The current spec’s owned SharedPulse also excludes a non-shareable borrowed observer. Both are open API work, exposed by this experiment.

Use owned bytes/control when work must escape the caller’s lifetime. A worker hop should move existing ownership or clone an existing shared handle once. Failure to share a Pulse must remain explicit; replacing it with cancellation alone would lose progress.

Browsing needs a retained native owner

Byte seeking and image selection are separate. A retained document keeps parser/index state, scoped image and level IDs, lazy listings and the source revision. A selected decode asks for native ranges; the driver answers them from a resident slice, file or remote source.

Open one document→List images / levels / channels→Select exact ROI→Request byte ranges

Those retained semantics already exist in the older design and are carried into this fork. The native TIFF witness covers tiled Gray8 roots and a reduced SubIFD. EXR, JXL and IMIJ collection behavior is not implemented here. The document driver and worker read bridge have separate copy/lifetime obligations; the single-image pointer controls do not qualify them.

Keep the guarantees. Remove required machinery.

  • Keep a local borrowed entry point: whole-file &[u8] and &dyn Pulse, with no mandatory box, runtime or shared ownership.
  • Keep the incremental/range protocol: source-owned windows, exact requests, batched rows, output ownership transfer and retained documents are useful mechanisms.
  • Keep admission and correctness: output interpretation, source identity, exact ROI, error causes, cancellation and pre-output policy remain requirements.
  • Make authoring and scheduling optional: coroutine state, per-batch worker hops and duplicate typed/dyn hierarchies need not be mandatory costs.
  • Do not retire the fast path yet: allocation parity is demonstrated by the cost control; latency parity and the complete replacement contract remain unqualified.
